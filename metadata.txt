about=Complementary attribute editor for vector layers. Does not replace the built-in Attribute Table (F6) or its default shortcut.
    Compared with the built-in table and other attribute-table plugins, it focuses on:
    - Field-remark packs: aliases, hover notes, and insert meanings in named packs shared across projects (not tied to one .qgz). Variables such as {{title}} when inserting values
    - Batch fill: constants, sequence around text, add text, expressions, and replace (one box for Standard / Around the match / Whole field, then constant or expression)
    - Settings: toolbar order, per-tool shortcuts (refused if QGIS already uses them), and parameters such as filter-follows-column and selected line length
    - Field mapping copy from a project layer, a file, or the Copy Features clipboard (WKT/WKB, GeoJSON)
    - Line-direction check: every filtered point on the start layer acts as a start; nearest start sets each line direction
    Use: select a vector layer, open from the toolbar or Vector menu, edit in the plugin window; save and rollback use the layer edit buffer.
    QGIS 3.28 through 4.99 (Qt 5 and Qt 6). No extra Python packages. UI: 中文, English, Español, Français, العربية, Deutsch, 日本語, 한국어; first launch follows QGIS then system locale; unmatched locales use English.

    - About lists each UI language in its own spelling: 中文, English, Español, Français, العربية, Deutsch, 日本語, 한국어
    - Line direction: every line end is a junction. When several lines leave one point, each flows outward; branches are never errors
    - Line direction: ends only matter on loops. A loop is cut at its end and both sides run toward it; ends off a loop change nothing. The result says how many ends cut a loop, and a pseudo-loop tells you to put an end there
    - Line direction: large looped networks check much faster
    - Settings → Parameters: Column headers (Field name only, Alias first, or Alias and field name)
    - Settings → Parameters: Default fill method (Remember last, or always Const, Sequence around text, Add text around, Expression, or Replace)
    - Saved expressions: a gear next to ε adds, edits, notes, reorders, and deletes expressions. Clicking the fill box drops them down; typing still works.
